## 3. 执行路线（失败才进入下一阶段）

按序推进，每一阶段只有未过门槛时才进入下一阶段；不允许跳级。

1. **阶段 A：插值诊断** —— 权重插值仅作诊断与兜底手段；不预设"插值收益线性可外推"，诊断结论只用于决定后续超参方向。
2. **阶段 B：56 万张精确来源平衡 Replay-only 对照** —— 全模型学习率 1e-5，2 epoch，reencode 概率 0.15；作为隔离"回放本身"贡献的对照实验（纯回放对照先行，是判定后续蒸馏贡献的前提）。
3. **阶段 C：Replay + 知识蒸馏（KD）** —— head 学习率 2e-5、stages 2-3 学习率 5e-6、stem 与 stages 0-1 全程冻结；不引入 anchor，不采用动态解冻。渐进解冻固化为"两 epoch 同构"，不中途变更冻结策略。
4. **阶段 D：残差适配器** —— 最后手段；与插值不构成重复（参数空间位移 vs 输入相关非线性修正），仅在 A-C 全部失败后启用。

里程碑即各阶段的门控评估完成时刻；任一阶段通过本轮绑定门槛即停止升级。

## 4. 本轮唯一绑定门槛清单（预注册）

判定工具：`scripts/compare_robustness_candidates.py`（新增本轮绑定门槛段）。以下默认值即为预注册值：

- 综合 robust score ≥ **0.9325**；
- CommunityForensics-Small per-source robust ≥ **0.9239**（绝对门槛）；
- GenImage per-source 下降 ≤ **0.003**；SID_Set per-source 下降 ≤ **0.003**；
- clean AUC 下降 ≤ **0.002**；
- 全局各退化族（jpeg / blur / scale / noise / color / crop）平均下降 ≤ **0.003**；
- 各来源任一退化族平均下降 ≤ **0.005**；
- noise 族平均下降 ≤ **0.002**，且 blur_2.0 单条件下降 ≤ **0.002**；
- 格式诊断：`audit_compression_history.py` 诊断视图的绝对 AUC 不劣于基线，且报告须给出配对下降；
- 噪声目标定位为"不得明显回退"，**不要求提升**。

旧五重门（`compare_robustness_candidates.py` 原有逻辑）降级为**历史参考报告**，不参与放行。

## 5. 九项修正记录（对初版评审的再评审结论）

1. 插值不做线性外推：插值诊断结果只描述已测点位，不外推至未测配比。
2. Replay-only 并非零代码改动：需要来源平衡的混合清单与重编码配置，属真实工程改动。
3. 学习率单点起步、按失败模式定向升级：仅允许一次定向重试；若失败模式为旧域已下降，禁止升学习率。
4. 渐进解冻固化为两 epoch 同构：不在训练中变更冻结/解冻策略。
5. reencode 0.15 只是缓解项而非解决方案：训练变换不改 CSV，Cramér's V 不作为训练后放行指标；格式项放行须比绝对 AUC + 配对下降（诊断视图）。
6. 本清单第 4 节为**唯一绑定门槛**，取代此前所有门槛表述。
7. anchor 暂缓：范数约定未定义，无可比性，引入前先补齐度量定义。
8. 适配器与插值非功能重复：适配器是参数空间位移，插值修正的是输入相关非线性行为。
9. 时间与显存均为估算值：每个阶段首跑必须实测，实测结果回写后再排期。

## 6. 密封纪律与早停

密封顺序（不可逆，单向开封）：

1. selection 集反复使用（本轮 12,000 selection）；
2. confirmation 集一次性开封（仅模型冻结后）；
3. WildFake 演示集观察一次，结果**不回流**任何决策；
4. 最后重校准阈值（现行 0.209），数字与评估产物必须一致。

显式例外（防泄漏断言）：允许以防泄漏断言为目的**只读** confirmation/selection 清单的 sha256 与 generator 列（如 `scripts/build_replay_manifest.py` 的三重断言）；**禁止**读取其标签用于任何指标计算。指标性开封仅限候选固定后的一次性验收。

训练内早停：per-epoch 门控 —— 旧域任一来源（GenImage / SID_Set）指标下降 > 0.005 即终止该次训练。
执行方式按阶段区分：
- 阶段三（Replay-only，走 `train.py` 路径）：per-epoch 早停由**人工监控 metrics 并终止进程**执行，已在 `outputs/replay_only_v1/REPORT.md` 核验；
- 阶段四（蒸馏脚本）：为**代码化自动护栏**。

## 8. 实验记录：候选密封验收（2026-08-29）

- 候选：model soup v1（两个蒸馏中间检查点权重 1:1 平均，单一模型）。该候选曾在 selection 集上通过全部 31 项绑定门槛，但其中两个来源级家族窄门为贴线通过，过门余量远小于测量噪声地板，验收时列为重点复核项。
- confirmation 唯一一次开封结果：候选综合与三来源格局与 selection 一致、无异常反转，31 门中 30 门通过；唯一失败项正是 selection 上预警的贴线窄门之一（SID 亮度家族降幅超限约 1.1e-4），复核认定贴线余量不构成稳健证据。
- 按预注册早停纪律：判定失败即停止，未消耗 WildFake 一次性观察额度，未做格式诊断复跑，未做任何归档；正式模型维持原基线不变。
- 内部集阈值重校准结论：候选分数分布下的最优阈值与现行冻结阈值差异远小于测量噪声，不构成明确更优，阈值维持不变。
- 工程教训固化：权重合并类候选若依赖贴线余量过门，应视为未通过；后续候选须在 selection 上以显著高于噪声地板的余量通过全部绑定门槛后，方可申请开封。
- 完整数字与产物见 `outputs/acceptance/ACCEPTANCE_REPORT.md`。

## 9. 最终结论：封板与新正式模型（2026-08-29）

- 新正式模型：残差适配器 v2（`outputs/adapter_v2/epoch_01.pt`）。在冻结基座之上叠加一个极小的残差分支，
  以旧域残差惩罚约束遗忘，按预注册协议在 31 项绑定门槛上全部通过（综合、目标来源与旧域格局、clean 均达标），
  且格式捷径诊断不劣于基线、冻结阈值 0.209 维持不变、推理开销可忽略。正式备份已设只读归档。
- 回退点：`outputs/multisource_blur_finetune/best.pt`（裸基座），自始至终未被修改，其既有备份同样未动；
  旧检查点加载行为不变已验证。若正式模型出现异常可直接切回，推理管线无需其他改动。
- 密封纪律执行情况：confirmation 集已按第 7 节红线在任务 #9 中完成唯一一次开封并永久消耗（判负早停）；
  WildFake 演示集对新正式模型完成了唯一一次观察（整体稳健度 0.9082，优于基线历史口径 0.9047，
  0.209 下 16 条件均值 0.8400 优于 0.8341），观察结果仅记录、不回流任何决策，此后观察额度用尽。
  阈值从未在 WildFake 上重校准。
- 贴线教训与门槛统计功效结论（本实验链的最终复盘）：源×族粒度窄门的测量噪声地板约 0.003~0.0045，
  贴线余量（1e-5~1e-3 量级）不构成稳健证据——模型汤候选即因贴线过门而在 confirmation 上翻车，
  蒸馏路线四个检查点的失败也全部落在该粒度。权重插值、纯回放、回放+蒸馏、权重合并四条路线均已证毕；
  最终成功路线是冻结基座 + 受罚残差分支：以结构性约束替代窄门博弈，把旧域降幅压入噪声地板之内。
  今后任何候选申请开封，必须以显著高于噪声地板的余量通过全部绑定门槛为先决条件。
- 完整证据链与数字见 `outputs/adapter_v2/final_acceptance/FINAL_ACCEPTANCE.md`。
