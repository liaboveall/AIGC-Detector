# Security policy

## Supported version

Security fixes are applied to the latest public release and the `main` branch.

| Version | Supported |
|---|---|
| 2.0.x | Yes |
| 1.x | Critical fixes only |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of a
public issue when a report could expose users, credentials, unsafe model loading, or a
code-execution path. Include affected versions, reproduction steps, expected impact,
and any suggested mitigation.

Model accuracy errors, dataset limitations, and false positives are important but are
normally tracked as model-quality issues rather than security vulnerabilities. Never
include private images, credentials, or restricted dataset content in a report.
